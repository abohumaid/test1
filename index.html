Standard Input & Output Streams

<<

cout — Character Output

<< Insertion

Sends text, numbers, and evaluated expressions to the console/screen.

cout << "Hello World!"; cout << "Welcome" << endl;
>>

cin — Character Input

>> Extraction

Extracts typed user input from the keyboard and stores it into a variable.

cin >> age; cin >> x >> y;

If Statements in C++

BRANCHING EXECUTION LOGIC FLOW
if (condition)
Executes solely when the test condition evaluates to true.
else if (other)
Evaluated only if all preceding if-conditions failed.
else
Universal fallback executed when no conditions are met.
COMPARISON: == != < > >=
LOGICAL: && AND || OR ! NOT

If Statement in Action

pass_fail.cpp if - else
#include <iostream> using namespace std; int main() { int score = 85; if (score >= 50) { cout << "Passed!" << endl; } else { cout << "Failed!" << endl; } return 0; }

student_grades.cpp else if
#include <iostream> using namespace std; int main() { int score = 85; if (score >= 90) { cout << "Grade: Excellent (A)"; } else if (score >= 75) { cout << "Grade: Very Good (B)"; } else if (score >= 50) { cout << "Grade: Pass (C)"; } else { cout << "Grade: Try Again (F)"; } return 0; }
⚡ Test Score:
> Terminal Output: Grade: Very Good (B)
if يُفحص أولاً: إذا كان الشرط صحيحاً (true) يتم تنفيذ الكود الذي بداخله فقط.
else if شرط إضافي: يُفحص فقط في حال كانت الشروط السابقة غير متحققة (false).
else المسار البديل: يُنفذ تلقائياً إذا لم يتحقق أي شرط من الشروط السابقة.
